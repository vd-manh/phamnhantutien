# Câu lệnh các hàng động tác của Độc Tu (`doc_ai`)

Sinh bằng `tools/gen_cau_lenh_doc.py`. Phần tạo hình, bảng xoay và vũ khí: `docs/CAU_LENH_DOC_TU.md`.

Cách làm (bộ động tác chuẩn, mục 3 của `QUY_TRINH_NHAN_VAT.md`):

- 4 hàng × 5 hướng, mỗi hàng là **một cuộc trò chuyện Gemini mới**; gắn ảnh `doc/doc_<hướng>_ref_nb_wide.png` của đúng hướng đó.
- Gemini vẽ **tay không**: tay cầm quạt nắm chặt như cầm chuôi, tay kia mở. Code vẽ quạt vào nắm tay, vẽ độc châm bay ra.
- Lưu ảnh thành `doc/doc_<hướng>_<động tác>.png`, gửi Claude kiểm tra từng ảnh.
- **Đánh thường** (chốt 16/11/2026): phẩy quạt bắn 3 mũi độc châm toả hình quạt (code vẽ); trúng thì nhiễm độc, mất máu dần.
- **Thi pháp**: khung 1–2 tụ sương độc trước ngực (giữ khi vận chiêu), khung 3–6 vung quạt phóng độc.

Thứ tự: `idle`, `run` (5 hướng) → `attack` → `cast`.
